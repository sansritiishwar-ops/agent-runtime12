# Blog Formatting for Publication

Use this skill when you have completed research and gathered content for a blog post, and now need to format it into a polished, publication-ready document. This skill ensures your output meets professional publishing standards.

## When to Use This Skill

**Use this skill when:**
- You have researched content and need to format it as a blog post
- You need to transform draft content into publication-ready format
- You want to ensure the blog post meets professional structure and readability standards
- You are finalizing content for immediate publishing

**Do NOT use this skill when:**
- You are still in the research or information-gathering phase
- You are creating technical documentation or academic papers (different formatting standards apply)
- You are writing social media posts or short-form content (different format)
- You need to create images or media content (this skill focuses on text formatting)

## Structure Requirements

### Title and Heading Hierarchy
- **Main Title (H1)**: One compelling, clear H1 title that captures the blog post's core topic
- **Section Headings (H2)**: Use H2 for major sections (typically 3-5 main sections)
- **Subsection Headings (H3)**: Use H3 for subsections within H2 sections
- **Avoid H4 and below**: Keep hierarchy simple; if you need H4, consider reorganizing

### Introduction Pattern
- **Hook**: Start with an engaging opening sentence that captures attention
- **Context**: Briefly establish why this topic matters to the reader
- **Preview**: Indicate what the post will cover without giving everything away
- **Length**: Keep introductions to 2-4 paragraphs (150-250 words)

### Body Structure
- **Logical flow**: Organize sections in a logical sequence (chronological, problem-to-solution, simple-to-complex)
- **Paragraph length**: Keep paragraphs to 3-5 sentences (50-100 words maximum)
- **Section length**: Balance section lengths; avoid one section dominating the post
- **Transitions**: Use transition phrases between sections to maintain flow

### Conclusion Pattern
- **Summary**: Briefly recap the main points covered
- **Key takeaway**: Emphasize the most important message
- **Call-to-action**: Include a clear next step for readers (comment, share, try something, read more)
- **Length**: Keep conclusions concise (2-3 paragraphs, 100-150 words)

## Readability Optimization

### Sentence Construction
- **Vary sentence length**: Mix short (5-10 words) and medium (15-20 words) sentences
- **Active voice preferred**: Use active voice for clarity and directness (e.g., "The team developed" instead of "was developed by")
- **One idea per sentence**: Keep sentences focused on a single point
- **Avoid jargon**: Use plain language; explain technical terms when necessary

### Clarity and Flow
- **Transition words**: Use transitions like "However," "Additionally," "For example," "As a result" to connect ideas
- **Concrete examples**: Support abstract concepts with specific examples or scenarios
- **Scannable content**: Structure content so readers can skim and still grasp main points

### Tone and Voice
- **Consistent tone**: Maintain a consistent voice throughout (professional yet conversational)
- **Second person**: Consider using "you" to engage readers directly
- **Contractions acceptable**: Use contractions ("don't," "it's") for a more natural, conversational tone

## Visual Formatting in Markdown

### Lists
- **Bullet points**: Use for unordered items, features, or benefits
  ```markdown
  - First item
  - Second item
  - Third item
  ```
- **Numbered lists**: Use for sequential steps, rankings, or chronological items
  ```markdown
  1. First step
  2. Second step
  3. Third step
  ```
- **List length**: Keep lists to 3-7 items for optimal readability

### Blockquotes
- Use for emphasis, key definitions, or important quotes:
  ```markdown
  > This is an important callout or quote that deserves emphasis.
  ```

### Code Blocks
- When relevant, use code blocks for technical examples or formatted text:
  ```markdown
  ```language
  code example here
  ```
  ```

### Image Placeholders
- Include descriptive placeholders where images would enhance content:
  ```markdown
  [Image: Description of what image should show]
  ```
- Suggest images every 300-500 words to break up text

### Bold and Italic
- **Bold**: Use for key terms, important concepts, or section emphasis
- *Italic*: Use for slight emphasis, book/article titles, or foreign terms
- Don't overuse: Too much formatting reduces its impact

## SEO Best Practices

### Meta Description Suggestion
- After completing the post, suggest a meta description (150-160 characters)
- Include primary keyword and value proposition
- Write as a compelling preview that encourages clicks

### Keyword Integration
- **Natural placement**: Integrate primary and related keywords naturally within content
- **Avoid keyword stuffing**: Focus on readability first; keywords should feel organic
- **Header keywords**: Include relevant keywords in H2 and H3 headings where appropriate
- **First paragraph**: Try to include the primary keyword early in the introduction

### Linking Strategy
- **Internal links**: Suggest 2-3 opportunities for internal links to related content (if applicable)
- **External links**: Include 1-3 authoritative external sources to support claims
- **Anchor text**: Use descriptive anchor text, not "click here" or generic phrases
- **Link placement**: Place links naturally within content where they add value

### URL-Friendly Title
- Suggest a URL slug based on the title (lowercase, hyphens, no special characters)
- Example: "How to Format Blog Posts" → `how-to-format-blog-posts`

## Professional Polish

### Grammar and Style
- **Proofread**: Review for spelling, grammar, and punctuation errors
- **Consistency**: Maintain consistent terminology throughout (e.g., "e-commerce" vs "ecommerce")
- **Number formatting**: Be consistent with number formatting (spell out one through nine, use numerals for 10+)
- **Date formatting**: Use consistent date format throughout

### Fact-Checking
- **Verify statistics**: Ensure all numbers, statistics, and data points are accurate
- **Check claims**: Verify that any factual claims can be supported
- **Update dates**: Ensure any time-sensitive information is current

### Citations and Attribution
- **Source attribution**: Credit sources for statistics, quotes, or unique insights
- **Citation format**: Use inline links or footnote-style references
- **Example**: "According to [Source Name](URL), 70% of users prefer..."

### Call-to-Action (CTA)
- **Placement**: Include CTA in conclusion, and optionally mid-post for longer articles
- **Clarity**: Make the desired action clear and specific
- **Examples**: "Share your thoughts in the comments," "Try this approach and let us know," "Subscribe for more insights"

## Length and Pacing Guidelines

### Target Word Counts
- **Short-form blog post**: 600-1,000 words (quick reads, listicles, news)
- **Standard blog post**: 1,000-1,500 words (how-tos, explanations, tutorials)
- **Long-form blog post**: 1,500-2,500+ words (comprehensive guides, research-based)

### Section Pacing
- **Introduction**: 10-15% of total word count
- **Body**: 70-80% of total word count, divided among main sections
- **Conclusion**: 10-15% of total word count

### Content Flow Validation
- **Read-through test**: The post should flow naturally from start to finish
- **Skim test**: Headers and first sentences should convey the main narrative
- **Information balance**: Avoid front-loading or back-loading too much information

## Publication Checklist

Before considering the blog post ready for publication, verify:

### Structure Checklist
- [ ] One clear H1 title
- [ ] Logical H2 section headings (3-5 sections)
- [ ] H3 subsections where appropriate
- [ ] Clear introduction with hook and preview
- [ ] Organized body content with logical flow
- [ ] Conclusion with summary and call-to-action

### Readability Checklist
- [ ] Paragraphs are 3-5 sentences maximum
- [ ] Sentences vary in length and structure
- [ ] Active voice used where appropriate
- [ ] Transition words connect ideas smoothly
- [ ] Tone is consistent throughout
- [ ] Content is scannable (headers, lists, formatting)

### Visual Formatting Checklist
- [ ] Bullet points or numbered lists used appropriately
- [ ] Key concepts highlighted with bold or blockquotes
- [ ] Image placeholders included where helpful
- [ ] Proper Markdown formatting applied throughout

### SEO Checklist
- [ ] Meta description suggested (150-160 characters)
- [ ] Primary keyword integrated naturally
- [ ] Keywords in headers where appropriate
- [ ] Internal link opportunities identified
- [ ] External authoritative sources linked
- [ ] URL-friendly slug suggested

### Polish Checklist
- [ ] Proofread for grammar and spelling
- [ ] Facts and statistics verified
- [ ] Sources properly attributed
- [ ] Consistent terminology and formatting
- [ ] Call-to-action is clear and compelling

## Output Format

Present the formatted blog post in Markdown, followed by:

1. **Suggested Meta Description**: [150-160 character description]
2. **Suggested URL Slug**: [url-friendly-slug]
3. **Word Count**: [total word count]
4. **Estimated Reading Time**: [X minutes]
5. **Internal Link Opportunities**: [List of 2-3 suggested internal link topics]
6. **Publication Readiness**: [Confirmation that the checklist is complete]

## Example Structure

```markdown
# [Compelling H1 Title]

[Engaging introduction with hook, context, and preview - 2-4 paragraphs]

## [First Main Section - H2]

[Content organized in 3-5 sentence paragraphs with clear points]

[Support with examples, data, or explanations]

### [Subsection if needed - H3]

[Detailed points within the main section]

- Bullet point for clarity
- Another bullet point
- Third bullet point

## [Second Main Section - H2]

[Continue logical flow from previous section]

> Important callout or key definition in blockquote

[More content with natural keyword integration]

[Image: Descriptive placeholder for relevant visual]

## [Third Main Section - H2]

[Build toward conclusion with substantial content]

## Conclusion

[Summary of main points - 2-3 paragraphs]

[Key takeaway and call-to-action]

---

**Suggested Meta Description**: [150-160 characters with primary keyword and value proposition]

**Suggested URL Slug**: descriptive-blog-post-title

**Word Count**: 1,250 words

**Estimated Reading Time**: 5 minutes

**Internal Link Opportunities**:
- Related topic 1
- Related topic 2
- Related topic 3
```

- "This blog post is formatted and ready for publication."
- Mention any specific strengths (e.g., "strong SEO optimization," "excellent readability scores")
- Note any considerations (e.g., "Consider adding custom images to the placeholders before publishing")
